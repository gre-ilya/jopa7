# Преобразования WGS-84 ↔ ПЗ-90.11 ↔ СК-42

Самодостаточный модуль (`ru_geo.h` / `ru_geo.cpp`, чистый C++17, без зависимости
от Qt и GPSBabel) для перехода между тремя системами координат российской
геодезии **7-параметрическим** преобразованием Гельмерта по модели
**ГОСТ 32453-2017**.

В отличие от 3-параметрических датумов в `jeeps/gpsdatum.h` (точность ~метры),
здесь используются полные 7 параметров (сдвиг + 3 поворота + масштаб). ПЗ-90.11
выступает узлом-хабом: любая пара считается цепочкой `A → ПЗ-90.11 → B` в
геоцентрических (ECEF) координатах.

## Схема

```
geodetic(B,L,H) --[эллипсоид источника]--> ECEF --[7-парам. Гельмерт]--> ECEF --[эллипсоид приёмника]--> geodetic(B,L,H)
```

Эллипсоиды: WGS-84 (`a=6378137, 1/f=298.257223563`), ПЗ-90 (`a=6378136,
1/f=298.25784`), Красовского 1940 для СК-42 (`a=6378245, 1/f=298.3`).

## Использование

```cpp
#include "ru_geo.h"
using namespace rugeo;

Geodetic wgs{55.7558, 37.6173, 150.0};          // широта, долгота (град), H (м)
Geodetic sk42 = convert(wgs, Datum::WGS84, Datum::SK42);
Geodetic pz   = convert(wgs, Datum::WGS84, Datum::PZ9011);
Geodetic back = convert(sk42, Datum::SK42, Datum::WGS84);   // обратно, точно
```

Доступны и низкоуровневые блоки: `geodeticToEcef`, `ecefToGeodetic`, `helmert`.
Обратное преобразование Гельмерта реализовано **точным** обращением матрицы 3×3,
поэтому round-trip A→B→A воспроизводит исходные координаты до машинной точности.

## Сборка и проверка

```sh
qmake ru_geo.pro && make && ./ru_geo_test
# или без qmake:
g++ -std=c++17 ru_geo.cpp ru_geo_test.cpp -o ru_geo_test && ./ru_geo_test
```

`ru_geo_test` гоняет round-trip по всем парам систем (должно быть `ALL PASSED`)
и печатает примеры пересчёта.

## ⚠️ Параметры преобразований — СВЕРИТЬ перед продакшеном

Числовые параметры собраны в **одном** месте — блок `DATUM TRANSFORM PARAMETERS`
в `ru_geo.cpp`:

- **СК-42 → ПЗ-90.11** — стандартный 7-параметрический набор ГОСТ 32453-2017
  (Δ = +23.557 / −140.844 / −79.778 м; ω = −0.0023″ / −0.34646″ / −0.79421″;
  m = −0.228·10⁻⁶).
- **WGS-84 → ПЗ-90.11** — по умолчанию **нули**: ПЗ-90.11 согласована с
  WGS-84 (G1150)/ITRF2008 на уровне нескольких сантиметров. Если ваш экземпляр
  ГОСТ даёт ненулевые значения — впишите их сюда.

Я не могу гарантировать каждую цифру и знак по памяти — **обязательно сверьте
весь блок с авторитетным текстом ГОСТ 32453-2017** перед использованием в
расчётах. Менять нужно только этот блок; вся геометрия и соглашение о знаках
вынесены отдельно.

Соглашение о знаках — «position vector» (Bursa–Wolf), как в ГОСТ:

```
| X' |   | dX |           |  1    wz  -wy | | X |
| Y' | = | dY | + (1+m) * | -wz   1    wx | | Y |
| Z' |   | dZ |           |  wy  -wx   1  | | Z |
```
